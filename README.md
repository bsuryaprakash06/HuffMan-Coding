# Huffman Coding

Implementation of the Huffman coding lossless data compression algorithm developed for coursework in data structures and algorithms. The project demonstrates character frequency analysis, binary tree construction, and prefix-free code generation in Python.

## Contents

- `HuffMan-Coding.ipynb` - Jupyter Notebook implementing node tree structures, frequency mapping, Huffman tree generation, and character code assignments.
